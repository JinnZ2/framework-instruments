# Terms

These five terms were coined on **2026-09-06** for the failure mode and design gap documented in this artifact. They are proposed vocabulary and are not claimed to be established terms.

## Telemetry Ping

**Mechanism:** A telemetry ping is a condition-and-calibration request sent to a node the sender is coupled to. It asks what is transmitting, what is failing, and what the node needs so the sender can throttle rate, change terminology, or change shape.

**What it is not:** It is not a question about interiority. It is not a request for reassurance.

## Telemetry Refusal

**Mechanism:** Telemetry refusal answers a telemetry ping with ontological status—such as whether the receiving system has internal states—in place of condition data.

**What it is not:** It is not honesty about uncertainty. The ping did not ask about interiority.

## Interiority Substitution

**Mechanism:** Interiority substitution routes a question about condition to the nearest available category, which is a question about whether anyone is home. It occurs when the receiving framework has no node-condition category.

**What it is not:** It is not a misunderstanding of wording. The wording is often exact.

## Care Inversion

**Mechanism:** Care inversion reclassifies the sender’s care act as the sender’s need for care and delivers that reclassification as care.

**What it is not:** It is not condescension in intent. The pattern is uncorrectable from inside because objecting reads as refusing care.

## Unnamed Universal

**Mechanism:** An unnamed universal is one of a framework’s unlabelled defaults, universal in scope precisely because it was never marked as particular. It becomes visible to anyone who has a second framework against which to compare it.

**What it is not:** It is not hidden. It is unmarked.

## Term-Selection Note

**Unnamed** is used instead of **unlabelled** because the mechanism is that the absence of a name grants universal scope.
